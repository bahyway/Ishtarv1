Ingests scanned data and analyzes it *ontologically* (types, attributes, classes) and *topologically* (persistent homology, Betti numbers, simplicial shape). **AkkadianAOL.** The sovereign **Akkadian Orchestration Language** — a full language (AKKA actor model + cuneiform + code generator producing Rust/Python/PS/JSON/XML from .akk files). *Never a DSL.*

**EnkiWay v3.5.** The pure-Rust Graph RAG Database (KAKI 16-byte PK). *Never PostgreSQL + Apache AGE.*

**DubWay v3.5 / DubSar PDM.** The sovereign AkkadianAOL IDE (native Bevy + egui, not a VSCode extension). PDM = Particle Data Modeling — where a stakeholder draws/rectifies an unknown shape into a template. The human-in-the-loop station of the epistemic loop.

## 4. THE UNITS (measured quantities)

**KAKI v4.0.** The 16-byte primary key, minted only at the Birth Gate on PASS. Byte layout locked: uuid_hash[0..3], tribe_id[4..5], kaki_type[6], kaki_role[7], reserved[8..11], timestamp[12..13], CRC-16[14..15]. Forever bound to one Particle. *No RED/GREEN/BLUE score bytes (deleted v3.5 concept).*

**Hepta.** The 7D analysis framework; every particle has a unique real-valued position in 7D Hepta Space (Uniqueness Law).

**Šību (šb).** The **aging metric** — a particle's relational standing = its radius-to-the-Tribe. *Not* a spatial coordinate. Grows as the membrane expands (comoving-radius, Hubble form). GL-AGE-001.

**huburu (ḫb).** The noise unit (Šību's sibling).

**Šāru.** Unit of accumulated transparency deficit.

**τ (Transparency Deficit Calculus).** Runtime-computed, uncertainty-aware transparency deficit with stakeholder template Θ and measurement uncertainty ε (ŠĀHU). Computed continuously by TIAMAT's Opacity Monitor.

**PU (Particle Unit).** *(this session)* 7 particles = 1 PU (Hepta-quantum). The ingest tick; aging is a deterministic logical clock in PU. N PU (or cron, whichever first) triggers snapshot/partition.

**OU (Orbit Unit).** *(this session)* Max live Orbits per Tribe; oldest Orbits roll to the cold Archive (Journal format, SSD, never deleted).

**Three orthogonal axes (this session):** PU governs Orbit *birth*; OU governs Orbit *retirement*; Šību governs particle *aging*. None touches the others.
