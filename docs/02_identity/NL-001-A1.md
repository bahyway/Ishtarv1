# NL-001-A1 — Artifact Name Registry

Sub-registry of NL-001 (Release Codename Law,
`docs/15_howto/BAHYWAY_V4_ARCHITECTURE_REFERENCE_2026-07-11.md` §8.1):
while gods name engines/calculi, cities name structures, and
kings name eras, ARTIFACTS (binary formats, wire encodings,
non-engine, non-structure named things) get their own pool,
tracked here.

Started 2026-07-26 (PB-255) — this is the first entry.
TUPSIMATI (the config tablet format, PB-169) predates this
registry and was never formally recorded anywhere; added
below for a complete record rather than left as a
retroactive gap.

| Name | What it names | Sealed by | Status |
|---|---|---|---|
| TUPSIMATI | Config tablet format | PB-169 | Real, in use — recorded here retroactively (2026-07-26), was not previously registered anywhere |
| BUZU | Bivector-orbit binary chunk (GL-VIZ-001 §2) | PB-255 (named), PB-256 (byte layout sealed) | Fully sealed — 32-byte header, 65536-particle chunks, FNV-1a checksum — see `docs/07_file_formats/GL-VIZ-001.md` §2/§5 |

## Considered and set aside

- **PUZUR** (puzru, "secret/shelter") — considered for the
  chunk format BUZU now names, returned to this pool, meaning
  noted with respect. Available for a future artifact.
- **ERISHUM** (king of Assur) — considered for the same, but
  withdrawn from this pool: per NL-001, kings name eras, not
  artifacts. Reserved to the era pool instead (alongside
  Gudea, Zagesi).

## Girsu Extension Clause (sealed by the Architect, PB-195)
1. NAMES FOR BEINGS, NUMBERS FOR RITES. Girsu extensions are
   components, not playbooks: they carry NAMES. Sequence
   lives only in the GX registry, never in the name.
2. Display-name pattern: Girsu + ServedComponent + Function,
   one unbroken CamelCase word per the Orthography Clause —
   e.g. GirsuEnkiDBConnector, GirsuHeptaScriptLinter,
   GirsuKakiInspector. No underscores, no hyphens, no
   serial suffixes (Ext01-class names are unlawful).
3. Technical id: the package.json identifier follows the
   VSCodium platform's lowercase kebab-case (e.g.
   girsu-enkidb-connector) — the same lawful accommodation
   the Rust crates make to their toolchain. Display name
   obeys NL-001; technical id obeys the platform.
4. Registry: every extension registers a GX-nnn line in
   CAT-001 (name · technical id · status · sha256 of the
   .vsix). Retirement flips status; the number is never
   reused. Ordering, lineage, and audit live here.
