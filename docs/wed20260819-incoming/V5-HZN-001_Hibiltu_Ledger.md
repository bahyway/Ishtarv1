## 1. The Question (stated once, so it is never lost)

After an Abūbu event, count the **Particle Units that fractured and mixed
into the soil shell** — the ±10 cm layer either side of the pipe (the
*Ḫibiltu shell*). From that count derive:

- **Cost of loss** vs **cost of prevention** — the PRESCRIBE stage of the
  Analysis-to-Solution law applied to money: what the Madanu repair at
  T_rupt − τ would have cost against what the earth drank.
- **Why there** — join against the inquest ledger (A3 first mover) and the
  simmu registry (A4 birth location): the causal chain already names the
  point; Ḫibiltu prices it.
- **Recurrence** — does the crack return to the same joint? A census over
  NUZI rupture lineage per location: same-place ruptures are a corridor
  verdict (design/soil/pressure regime), not a particle verdict.

## 2. Why v4.0 already pays for this (no redesign needed)

Everything Ḫibiltu will count, v4.0 already records:

| v5.0 need | v4.0 source (already sealed) |
|---|---|
| who spilled | RUPTURE-WITNESS Event KAKIs (A3 §1) |
| where the tear was | tear-region geometry + calibration (A2 §1, NUZI-sealed) |
| how much, in what unit | PU/OU (A2 §1) |
| when, in causal order | biography ledger + inquest (A3) |
| why there | simmu birth location + first mover (A4, A3) |
| has it happened before | NUZI rupture lineage, append-only |

The only genuinely new v5.0 work: the **soil-mixing model** (transport of
spilled PU into the shell — soil class, saturation, fluid type) and the
**cost calculus** (prevention price vs loss price per corridor). Both are
readings of the archive plus two new sealed models — no change to any v4.0
law, byte layout, or pipeline.

## 3. Naming note (for the eventual CSR-08)

*Ḫibiltu* is a ledger/concept, not an engine — under NL-001 it needs no god.
If it grows an engine in v5.0, the presiding name must come from the legal/
restitution register (the code-givers' court), proposed then, not now.

## 4. The Trigger Clause (the only door)

This tablet converts to a chartered work item **only if**:
(a) investors explicitly request spill/cost accounting, **and**
(b) the v4.0 completion law's gates are green at that time.
Absent both, it sleeps in NUZI. An investor request alone does not override
the completion law; it schedules Ḫibiltu *behind* it.
