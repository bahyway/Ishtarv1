## 1 · What ε is (one sealed definition, many readers)

**ε (epsilon) is the FCA closure gap: a deterministic, provable measure of how
far a particle's attributes are from cleanly closing to a sealed concept.**
ε = 0 → the particle belongs, provably (clean closure). ε large → the particle is
ambiguous, and the number states *how* ambiguous.

**One definition, many readers (monism for ε).** ε is computed in exactly one
place by exactly one formula (the closure gap). Every HeptaScript built-in and
every naṣāru render *reads* that single ε; none recomputes "uncertainty" its own
way. The failure mode of first-class uncertainty is *many* disagreeing scores a
query can shop between — forbidden here by single-source definition.

**ε is provenance, not fact.** ε is a measured property of a *query against the
current shape*, never a truth about the world. It rides *alongside* a value,
tagged, never folded *inside* a GOLDEN value. GOLDEN ⟹ verified fact still holds
(GL-GOV-002).

## 2 · The three disciplines (from the Never-Averaged Theorem)

**2.1 · Carried.** ε travels with every particle through every query and render,
as a first-class value `ε(particle)`. It is always available, always free
(the closure is computed anyway).

**2.2 · Never averaged.** ε aggregates by **envelope / worst-case only**. Averaging
ε across a population produces a deceptively reassuring figure that masks the
single particle with the catastrophic gap. Therefore `AVG(ε)` is a **forbidden
form** (does not parse, GL-GOV-002 §3.4). The only aggregators are `MAX(ε)`,
`ENVELOPE(ε)`, and `WORST(ε) WITH location` — and each reports *where* the worst
gap lives, not merely its size.

**2.3 · Never decisive.** ε may **guard** (`PROVE ... WITH ε < τ`, enforcing the
stakeholder template Θ at query time) and **triage** (`SORT BY ε DESC`, surfacing
the most-uncertain for the Steward first). ε may **never decide**: no particle is
admitted to a tribe *because* its ε is low. Placement is by FCA closure
(*derived*), never by ε (*measured*). ε routes attention; it never replaces the
proof.

## 3 · ε as a lens (fragmentation as located Unknown mass)

**The inversion:** ε is not opacity to be minimised — it is a *measurement* that
reveals where the current shape is incomplete. A cluster of high-ε particles is
the shadow of a concept the formal context has not yet captured: a **hole in the
lattice** (the object of Ganter's attribute exploration).

**3.1 · Fragmentation is measured, counted, located.** The lens reports the
Unknown not as a blur but as a population with mass and position:
`UNKNOWN { count, Hepta-centroid, spread, shared-unclosed-attributes }`.

**3.2 · Correlated failure distinguishes pattern from noise (computable).**
Random noise fails closure *scattered*; a hidden pattern fails *correlated* —
many particles missing the *same* would-be attribute, clustered in the *same*
Hepta neighbourhood. `SCAN Unknown ... GROUP BY closure-neighborhood` tests this:
a tight cluster = a candidate hidden concept; scattered = genuine noise. This
distinction is provable, and it is the heart of the lens.

**3.3 · The lens detects; it never names (GL-GOV-002).** A located Unknown
cluster proves *the current shape is incomplete*. It does **not** prove *what the
missing pattern is*. These are two different claims; the lens makes only the
first. Naming the concept is a `PROPOSE ... WITNESS` routed to the ranked
authority (GL-GOV-001). The detector and the namer are separated by grammar.

**3.4 · The terminal action is a witnessed proposal.** When the lens finds a
correlated Unknown cluster, it mints a **candidate-concept proposal** (extent =
these N particles, location = this Hepta region, evidence = their shared unclosed
attributes) into the attribute-exploration loop. The Steward/Architect confirms
it (sealing a new concept, with witness) or refutes it (with a counterexample).
The lens finds the hole; the authority fills it.

## 4 · The honesty contract, grounded in ε
FACT / WEAK / GHOST / NONE (GL-HS3-001) map to ε bands: low-ε clean closure →
**FACT**; rising ε → **WEAK**; no closure → **GHOST** (needs research); absent →
**NONE**. ε gives the four-outcome contract a real, computed number instead of a
heuristic.
