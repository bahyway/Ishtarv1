# Ningišzida → Ninazu Rename — 2026-08-21

The navigation engine landed yesterday (Mon20260817 delivery, GL-NAV-003,
`workspace/bahyway_v4/crates/ningiszida`) is renamed **Ninazu**, per the
Architect's explicit decision while reviewing the Tus20260818 Master
Glossary staged at `docs/tus20260818-incoming/`: *"Ninazu, because
ningiszida is difficult to pronounce."*

This confirms and completes a correction the glossary had already flagged
independently — see `docs/tus20260818-incoming/README.md`'s batch 2 note.
The glossary's own text: *"Ninazu = oldest Sumerian underworld god,
Nergal's predecessor, 'custodian of the earth / steward of the
underworld,' father of Ningišzida. Renamed from Ningišzida this session
(Ninazu = the engine; Ningišzida = reserved as a child sub-engine, e.g.
the path-tracer)."*

## What changed

**The engine's name only — not the law ID.** GL-NAV-003 keeps its number
(that renumbering, from the delivered GL-NAV-001, was a separate fix for
a collision against the already-sealed `GL-NAV-001-flight-to-location.md`
and `GL-NAV-002-knowledge-graph-navigation.md`, documented in
`docs/13_changelog/MON20260817_LANDING_VERIFIED_2026-08-21.md`). Today's
rename only replaces "Ningišzida" with "Ninazu" wherever the engine is
named:

- `workspace/bahyway_v4/crates/ningiszida/` → `workspace/bahyway_v4/crates/ninazu/`
  (Cargo package `ningiszida` → `ninazu`, lib name to match). `cargo test -p ninazu`: 4/4 passing, no code changes beyond the name.
- `workspace/bahyway_v4/Cargo.toml` member path updated.
- `docs/09_observatory/GL-NAV-003-ningiszida-engine.md` → `GL-NAV-003-ninazu-engine.md`, with the name gloss corrected to the Ninazu genealogy above and a note reserving Ningišzida as a future sub-engine.
- `playbooks/playbook_350_ningiszida_engine.yml` → `playbook_350_ninazu_engine.yml`, `crate_dir` and verify commands updated to `crates/ninazu` / `cargo test -p ninazu`.
- `shala-prototypes/batch9_mon20260817_delivery/shala_najaf_navigator.html` — title, in-file comment, and console log updated to "Ninazu Navigator."
- `shala-prototypes/INDEX.md` — batch 9 heading and description updated.

Yesterday's original changelog entry (`MON20260817_LANDING_VERIFIED_2026-08-21.md`)
is left as the historical record of what was actually landed under that
name at the time — not rewritten to pretend it always said Ninazu. This
entry is the correction, recorded the same way the Tu20260818 QGIS session
recorded its own corrections: nothing silently vanishes, the prior name
stays visible in git history.

## Ningišzida's reserved future

Per the glossary, Ningišzida (Ninazu's mythological son) is reserved as a
name for a future child sub-engine under Ninazu — the glossary suggests a
path-tracer as one candidate. No such sub-engine exists yet; this is a
naming reservation only, not a scaffold.
