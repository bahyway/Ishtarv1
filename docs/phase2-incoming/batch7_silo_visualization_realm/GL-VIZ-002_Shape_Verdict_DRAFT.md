## Non-Matching Discovered Shapes · New / Template-Defect / Incomplete · The Map-Direction Discriminant

## 0 · The Question

A discovered shape (GL-VIZ-001) is matched by NESU distance against the
**Patterns Template Arsenal** (Universal ERD templates, sealed particles in
**EnkiMDB**, used inside the **DubSar PDM IDE**). When the shape matches no
template, the system must not merely say "no match." It must render a
**Verdict** — one of three — because the mismatch means one of three different
things, each with a different fix flowing in a different direction.

---

## 1 · The Discriminant (why 2 and 3 differ)

Options 2 and 3 are distinguished by **which side must change to make the two
shapes coincide** — and that is a TDA fact: the *direction* in which a
structure-preserving simplicial map fails.

Let S = discovered shape, T = nearest arsenal template. Stakeholders attempt to
replicate S in DubSar PDM using Simplicial-Complexity shapes; the replication
attempt IS the experiment that reveals map direction:

- **φ: S → T exists, φ⁻¹: T → S does NOT** → S carries features T lacks →
  **the data is richer than the template** → *Template Defect* (Option 2).
- **φ: T → S exists, φ⁻¹: S → T does NOT** → T carries substance S is missing →
  **the data has a hole** → *Incomplete/Hidden Shape* (Option 3).
- **neither map exists, S internally coherent, NESU high to ALL** →
  genuinely *New Shape* (Option 1).

One line: **Option 2 is the data teaching the template; Option 3 is the
template teaching the data.** The lesson's direction is the failing map's
direction.

## 2 · The Three Verdicts

### Verdict 1 · NEW SHAPE → new template
- **Signature**: high NESU to every template; S internally coherent (stable
  β-structure, no dangling features); no clean map either way.
- **Meaning**: nothing is broken; the shape is simply new.
- **Fix flows to**: the **Arsenal**. Mint S as a new Universal ERD template
  (sealed particle in EnkiMDB), enriching the library for all future ingests.
- **Authority**: Data Architect + Steward seal the new template (tri-approval
  sibling); it becomes arsenal canon.

### Verdict 2 · TEMPLATE DEFECT → amend the template
- **Signature**: φ: S → T exists but not back; S has persistent features T
  lacks (extra H₁ loops / H₀ components that recur across the corpus, i.e. real
  structure the template under-specified).
- **Meaning**: the **data is right; the template is stale** — prior public
  ingests under-defined it.
- **Fix flows to**: the **Template**. Version and re-seal the arsenal template
  to include the missing features (append-only; old version kept as scar).
- **Authority**: Data Steward (arsenal custodian) seals the amendment.

### Verdict 3 · INCOMPLETE / HIDDEN SHAPE → complete the data
- **Signature**: φ: T → S exists but not back; S has a **hole where T has
  substance** — a persistent H₁ loop that shouldn't be open (undetected
  dependency) or a missing feature (component absent from the conceptual
  definition).
- **Meaning**: the **template is right; the data/definition is incomplete** —
  a dependency exists in reality but wasn't captured, or the client omitted a
  component.
- **Fix flows to**: the **Data/Definition**. Route to Bābu B-6 PDM
  restructuring: the client/stakeholder supplies the missing dependency or
  component until φ⁻¹: S → T exists. TDA names the exact obstruction (which
  loop, which missing feature), so the request to the client is specific.
- **Authority**: Client Stakeholder supplies; Steward re-verifies conformance.

## 3 · The Verdict Rite (in DubSar PDM)

    DISCOVERED SHAPE S · no NESU match
      → replicate S with Simplicial-Complexity shapes in DubSar PDM
      → compute φ: S→T and φ: T→S (persistent homology, LamassuEngine)
      → CASE:
          neither map · S coherent      → VERDICT 1 (new template)
          S→T only (S richer)           → VERDICT 2 (template defect)
          T→S only (S has a hole)       → VERDICT 3 (incomplete data)
          both maps exist               → not a non-match; NESU re-check
      → emit VERDICT particle (Event KAKI + which maps existed + the named
        obstruction + ε), sealed, append-only, witnessed in StoryEngine.

Honesty coupling (GL-VIZ-001 D-1) applies: the morphology *proposes* the
verdict; the simplicial-map computation *proves* it. No verdict is sealed on
visual impression alone.
