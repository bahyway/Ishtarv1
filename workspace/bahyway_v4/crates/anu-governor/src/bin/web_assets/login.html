Sign in with a Sargon-format passport vault — the same sargon_vault.dat file the Sargon Passport Manager or Gilgamesh Master Key tools write. A gardener-privilege passport lets you watch a run and export the report; only an Architect-privilege (Gilgamesh-minted) passport can start, abort, skip, or retry.

Don't have a vault yet? There's nothing to sign in with the first time — open Sargon Passport Manager (issues a gardener-tier passport) or, for Architect/Gilgamesh privilege, Gilgamesh Master Key first, and create one there. On this host: ansible-playbook playbook_285_launch_sargon_or_gilgamesh_key_tool.yml (add -e tool=gilgamesh for the Architect ceremony instead).
