StoryEngine — Time-Travel Queries

محرك القصة — استعلامات السفر عبر الزمن
CQRS Architecture:
  • Write side: Append-only Journal
  • Read side: Event projection
  • State is never stored
  • State is always projected
  • No UPDATE. No DELETE. Ever.
Time-Travel Algorithm:
  1. Find snapshot ≤ target epoch
  2. Load snapshot state
  3. Apply delta Event-KAKIs since snapshot
  4. Return complete state at epoch T
Every state change adds a new Event-KAKI. The old state is always there. كل تغيير يضيف ختماً جديداً. الحالة القديمة لا تُمحى أبداً.
